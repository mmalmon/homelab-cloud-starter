# Polityka bezpieczeństwa

Zgłaszaj luki prywatnie przez GitHub: **Security → Report a vulnerability**.
Nie publikuj szczegółów w publicznych issues. Nigdy nie wklejaj tokenów,
haseł ani plików `.env`. Wzorce konfiguracji (`.env.example`) nie zawierają
sekretów; prawdziwe `.env` są ignorowane przez Git.
